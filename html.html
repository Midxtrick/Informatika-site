Факты об HTML

HTML — не язык программирования. Это язык разметки (HyperText Markup Language), который задаёт структуру документа, а не логику вычислений.
Первый сайт появился в 1991 году. Тим Бернерс-Ли создал его в ЦЕРНе, чтобы учёные могли обмениваться документами по гиперссылкам.
Браузер прощает многие ошибки. Если забыть закрывающий тег у простого абзаца, браузер часто всё равно отобразит страницу, но валидный код надёжнее.
HTML5 вышел в 2014 году. Он добавил семантические теги (<header>, <main>, <article>) и встроенную поддержку аудио/видео.

Теория HTML

Изучите основные строительные блоки веб-страницы, а затем закрепите их в разделе «Задачи».

1. Заголовки и абзацы (<h1>–<h6>, <p>)

Теги заголовков обозначают важность раздела: <h1> — главный заголовок страницы, <h2> — подзаголовок и так далее до <h6>. Обычный текст помещают в <p>. 

<h1>Мой первый сайт</h1>
<h2>О проекте</h2>
<p>HTML помогает структурировать текст на странице.</p>

2. Списки (<ul>, <ol>, <li>)

Маркированный список создаётся тегом <ul>, нумерованный — <ol>. Каждый элемент списка оборачивается в <li>. 

<ul>
  <li>Структура</li>
  <li>Стили (CSS)</li>
  <li>Интерактивность (JS)</li>
</ul>
Результат в браузере
  • Структура
  • Стили (CSS)
  • Интерактивность (JS)

3. Ссылки и выделение текста (<a>, <strong>, <em>)

Ссылка создаётся тегом <a href="...">. Для важного текста используют <strong>, а для логического акцента (обычно курсивом) — <em>. 

<p>Узнайте больше на <a href="https://developer.mozilla.org">MDN Web Docs</a> — это <strong>очень</strong> полезный ресурс.</p>
Результат в браузере

Узнайте больше на MDN Web Docs — это очень полезный ресурс.

4. Кнопки и поля ввода (<button>, <input>)

Интерактивные элементы позволяют пользователю отправлять данные или запускать действия. У <input> есть атрибут type (например, text или email) и placeholder. 

<input type="email" placeholder="Введите ваш e-mail" />
<button type="button">Подписаться</button>
