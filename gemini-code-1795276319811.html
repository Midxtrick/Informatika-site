Урок 4: Что такое CSS?

Если HTML — это каркас и скелет сайта (текст, картинки, структура), то CSS (Cascading Style Sheets) — это его одежда и дизайн.

Зачем нужен CSS?

С помощью CSS мы настраиваем цвета, шрифты, отступы, расположение блоков и темную или светлую тему.

Пример кода CSS:

Стили обычно пишутся внутри тега <style> в шапке сайта:

body {
    background-color: #0b0f19;
    color: #ffffff;
    font-family: Arial, sans-serif;
}
