Урок 1: Что такое HTML и как работают теги

HTML (HyperText Markup Language) — это язык разметки, с помощью которого создаётся структура всех сайтов. Он объясняет браузеру, где на странице заголовок, где обычный текст, а где картинка.

Как устроены теги?

Тег — это команда для браузера в угловых скобках < и >:

  • Открывающий тег начинает элемент: <h1>
  • Закрывающий тег завершает его (со слэшем): </h1>

Пример: <h1>Привет, мир!</h1>

Урок 3: Практика (Сложный уровень)

Списки создаются контейнером <ul> и пунктами <li>. Ссылки делаются тегом <a href="адрес">Текст</a>.

Задание: Меню из списка со ссылкой

Создай список <ul>, внутри которого есть хотя бы один пункт <li> и кликабельная ссылка <a href="...">.

Урок 4: Что такое CSS?

Если HTML — это скелет страницы, то CSS (Cascading Style Sheets) — это её дизайн: цвета, шрифты, отступы и фиолетовое оформление, которое ты видишь сейчас.

Пример кода CSS:

body {
    background-color: #0d0a1a;
    color: #cbd5e1;
    font-family: monospace;
}

Задание: Покрась текст в фиолетовый

Напиши абзац <p>, добавив ему атрибут style="color: purple;" (или любой другой цвет).
