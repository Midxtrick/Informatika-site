Страница 1: Каркас HTML и Текст

HTML создаёт скелет любого сайта с помощью тегов.

Главные теги документа:

  • <head> — настройки сайта и название вкладки.
  • <body> — видимая часть страницы (текст, фото, кнопки).

Текстовые теги:

  • <h1> ... </h1> — главный заголовок.
  • <p> ... </p> — обычный абзац текста.

Страница 2: Ссылки и Цвета CSS

Ссылки делаются тегом <a href="адрес">Текст</a>.

CSS отвечает за дизайн. Чтобы покрасить текст, добавляют атрибут style="color: цвет;".

🎨 Редактор цвета CSS:

Выбери цвет ниже и нажми кнопку, чтобы вставить готовый код в задание:

#8b5cf6 
<p style="color: #8b5cf6;">Цветной текст</p>
