Урок 1: Что такое HTML и как работают теги

HTML (HyperText Markup Language) — это язык разметки, с помощью которого создаётся каркас всех сайтов. Он объясняет браузеру, где на странице заголовок, где текст, а где картинка.

Как устроены теги?

Тег — это команда для браузера в угловых скобках < и >. Большинство тегов парные: открывающий <h1> и закрывающий со слэшем </h1>.

Урок 4: Что такое CSS?

CSS отвечает за дизайн сайта: цвета, шрифты и стили.

body { background-color: #0d0a1a; color: #cbd5e1; }

Задание: Стили текста

Напиши абзац с цветом через стиль: <p style="color: purple;">Текст</p>.
