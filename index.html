Урок 1: Как устроен сайт и его текст

Привет! Любой сайт в интернете строится с помощью HTML. Представь, что сайт — это человек: HTML — это его скелет, а CSS — красивая одежда.

Чтобы браузер понял твои команды, мы используем теги — слова в угловых скобках < >. Если забыл какой-то тег, нажми на кнопку «📖 Теория» вверху!

🛠 Твоё первое задание

Собери мини-страницу: напиши теги <head></head>, а ниже внутри <body>...</body> добавь главный заголовок <h1>Привет</h1> и абзац <p>Мой сайт</p>.

3. Для чего нужен тег <p>?

А) Чтобы вставить картинку
Б) Чтобы создать обычный абзац текста

4. Как правильно закрыть тег заголовка <h1>?

А) <h1>
Б) </h1>

Урок 2: Ссылки и Цвета (CSS)

Чтобы с твоего сайта можно было перейти на другой (например, в Google или YouTube), используют тег ссылки <a href="адрес">Текст</a>.

А чтобы сделать текст красивым и цветным, подключают стили CSS прямо внутри тега: <p style="color: purple;">Текст</p>.

📖 Полная шпаргалка по HTML и CSS

Сюда можно заглянуть в любой момент, если ты забыл, как пишется какой-нибудь тег или свойство!

1. Базовый скелет любого сайта

Каждый HTML-файл строится по этому шаблону:

<!DOCTYPE html>
<html>
  <head>
    <title>Название вкладки</title>
  </head>
  <body>
    <!-- Здесь пишется всё, что видно на экране -->
  </body>
</html>

2. Главные теги для текста и ссылок

  • <h1>Заголовок</h1> — самый крупный главный заголовок (от h1 до h6).
  • <p>Обычный текст</p> — текстовый абзац.
  • <strong>Жирный текст</strong> — выделяет важные слова жирным шрифтом.
  • <a href="https://google.com">Нажми сюда</a> — создаёт кликабельную ссылку на другой сайт.

3. Списки (для меню и перечислений)

Списки состоят из контейнера <ul> и пунктов <li> внутри него:

<ul>
  <li>Первый пункт</li>
  <li>Второй пункт</li>
</ul>

4. Основы дизайна на CSS

Чтобы раскрасить элемент, добавь внутрь открывающего тега атрибут style="...":

  • style="color: purple;" — меняет цвет текста (можно писать названия цветов на английском или коды вида #8b5cf6).
  • style="background-color: black;" — меняет цвет фона под текстом.
  • style="font-size: 24px;" — делает шрифт больше или меньше.
