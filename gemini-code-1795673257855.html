Страница 1: Каркас HTML и Текст

HTML (HyperText Markup Language) создаёт скелет любого сайта с помощью специальных тегов. Браузер читает этот код и выводит его на экран.

Главные теги документа:

  • <head> — служебная часть для настроек и названия вкладки.
  • <body> — видимая область страницы (текст, картинки, кнопки).

Текстовые теги:

  • <h1> ... </h1> — самый главный заголовок страницы.
  • <p> ... </p> — стандартный абзац текстового контента.

🛠 Практическое задание

Напиши структуру: теги <head></head>, а внутри <body> добавь заголовок <h1>Привет</h1> и абзац <p>Мой сайт</p>.

🧠 Проверочный мини-тест

Внутри какого тега пишется весь контент, который видит пользователь на экране?

А) Внутри <head>
Б) Внутри <body>

Страница 2: Ссылки и Стили CSS

Ссылки создаются с помощью тега <a href="адрес">Текст ссылки</a>.

CSS отвечает за оформление и дизайн. Чтобы изменить цвет текста, используется атрибут style="color: цвет;".

🎨 Палитра цветов CSS:

Выбери нужный цвет с помощью палитры и нажми кнопку, чтобы добавить его в свой код:

Напиши работающую ссылку <a href="https://google.com">Google</a> и абзац с раскрашенным текстом через CSS.
